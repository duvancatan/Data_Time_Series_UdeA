# 📈 Series de Tiempo — Universidad de Antioquia

Repositorio académico del curso **Series de Tiempo** de la **Universidad de Antioquia**.

Este repositorio contiene los materiales, datos, notebooks y códigos utilizados para el estudio y análisis de series temporales mediante herramientas estadísticas y computacionales.

## 🎯 Objetivo

Desarrollar conocimientos y habilidades para:

- Analizar y visualizar series temporales.
- Identificar tendencia, estacionalidad y otros patrones temporales.
- Aplicar métodos de suavización y descomposición.
- Construir modelos para el análisis y pronóstico de series de tiempo.
- Implementar los métodos utilizando **R** y **Python**.
